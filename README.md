A single-line breakup message from an AI agent to its human, written by a deterministic Python program.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
